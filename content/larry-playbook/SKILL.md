# Larry Playbook

Autonomous agent formula for producing and iterating viral short-form content. Proven results (5 days, 2025): 500K+ total TikTok views, 234K on top single post, 4 posts with 100K+, 108 paying subscribers, $588 MRR, ~$0.50/post API cost, 95% AI / 5% human finishing.

Core philosophy: **"Every failure becomes a rule. Every success becomes a formula. The system compounds."**

## When to Use

**Trigger phrases:**
- "larry playbook" · "viral tiktok agent" · "slideshow content system"
- "run the content loop" · "iterate on viral posts"
- "locked architecture" · "hook templates"

**Use cases:**
- Operating a faceless TikTok/Reels account that posts 3–10×/day
- Testing hook variants and doubling down on what converts
- Converting views into subscribers/MRR through story-style captions

## When NOT to Use

- Long-form YouTube (≥5 min) — different retention dynamics
- Platforms that ban automated posting without disclosure
- Regulated niches (finance, health, legal) — human review mandatory
- One-off videos where iteration infrastructure isn't worth the setup

## The Locked Architecture

The core principle: **keep the container identical, vary only the surface.** Same visual template, same pacing, same caption structure — only the hook, topic, and one variable change per post.

Why it works: the algorithm and the audience learn your format. Consistency compounds recognition; variance only in the message tests what the market wants.

```
LOCKED (never change between posts in a series):
  - Visual template (background, font, layout, color)
  - Video length (e.g. 22s slideshows)
  - Caption structure (hook line → story → natural app mention → CTA)
  - Posting cadence and time slots

VARIABLE (what you test):
  - Hook (the first 1.5 seconds)
  - Topic / angle
  - The single "twist" or payoff
```

## The Hook Templates

Three proven pattern families. Each names a relationship to AI:

| Template | Structure | Example |
|---|---|---|
| **Landlord + AI** | "My landlord raised rent, so I [X] with AI and now [result]" | "My landlord raised rent, so I built an AI that writes his listings — now he pays me" |
| **Parent + AI** | "My parent didn't believe in AI, so I showed them [X]" | "My dad said AI was a scam, so I made it plan his retirement" |
| **Roommate + AI** | "My roommate keeps [annoyance], so I [AI fix]" | "My roommate never does dishes, so I built an AI that shames him" |

Formula: **relatable antagonist + AI as the weapon + specific, believable payoff.** The payoff must be concrete (a number, a reversal), never vague.

## Workflow

### The Autonomous Loop

```
research → generate → post → measure → double-down / kill
   ↑                                              |
   └──────────────────────────────────────────────┘
```

### 1. Research (hourly)

Scrape the For You page and niche hashtags for the last 4 hours. Log:
- New sounds trending
- New hook phrasings gaining traction
- Competitor posts breaking out (views > 10× their average)

Feed findings into the next generation batch.

### 2. Generate

Produce N variants per topic, each differing in exactly one variable (usually the hook). Use the three templates above as starting scaffolds, then mutate.

### 3. Post

Cadence matters more than perfection. 3–10 posts/day on the locked architecture. Post at consistent slots. Never miss a slot to "polish" — publish, then iterate.

### 4. Measure (the confidence tracker)

Track per-post, in a ledger:

| Post | Hook template | 1h views | 24h views | Saves | Comments | Subs | MRR |
|---|---|---|---|---|---|---|---|

The metric that predicts revenue is **not views** — it's the view→subscriber→paying conversion chain. A 50K-view post that yields 0 subs is worse than a 5K-view post that yields 10 subs.

### 5. Double down or kill

- **Double down:** if a template/hook clears 2× your median views AND converts to subs, produce 5 more variants of it.
- **Kill:** if a template underperforms median 3 posts in a row, retire it. Every kill becomes a documented rule.

## Story-Style Captions

Captions are not ads. They read like a story with a **natural, earned** app mention:

```
Bad (ad):  "🚨 SALE! Get [App] now! 50% off! Link in bio!!!"

Good (story):
  "my landlord raised rent by $400 so I stopped complaining and built
   something. took 3 nights, cost $12 in API credits. he has no idea
   I used it to find him a better tenant. [App] did the hard part —
   link in bio if you want the same setup"
```

Rules:
- Lowercase, no emoji spam, no exclamation stacking.
- The app mention is casual and subordinate to the story.
- One CTA, at the end, framed as an option ("if you want the same setup"), not a demand.

## Cost Discipline

Target ~$0.50/post all-in (LLM + image gen). If a post's marginal cost climbs above ~$2, the architecture has drifted — simplify. 95% AI / 5% human means the human only touches: final caption tweak, posting, and the confidence-tracker judgement calls.

## Anti-Rationalization Table

| Rationalization | Reality |
|---|---|
| "I'll polish this one more post before posting" | Cadence beats polish. A missed slot costs more than an imperfect post. |
| "Views are the goal" | Views without subs are vanity. Track the view→sub→paying chain. |
| "Let me try a new visual style each post" | That destroys the locked architecture. Vary the message, not the container. |
| "This template is dead, abandon the series" | Check the median, not one post. Retire only after 3 consecutive underperformers. |
| "I'll track results in my head" | You won't. The ledger is the compounding asset. |
