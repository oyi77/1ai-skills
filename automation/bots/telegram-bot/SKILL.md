## Echo Bot — Minimal Working Example```python"""echo_bot.py — Run with: python echo_bot.py"""import osimport loggingfrom telegram import Updatefrom telegram.ext import Application, MessageHandler, filterslogging.basicConfig(level=logging.INFO)TOKEN = os.environ["TELEGRAM_BOT_TOKEN"]async def echo(update: Update, _):   await update.message.reply_text(update.message.text)app = Application.builder().token(TOKEN).build()app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, echo))app.run_polling()```---
## Command Handler with Argument Parsing```pythonfrom telegram import Updatefrom telegram.ext import CommandHandlerasync def price(update: Update, context):   """Usage: /price BTC or /price ETH"""   args = context.args   if not args:       await update.message.reply_text("Usage: /price <symbol>")       return   symbol = args[0].upper()   # Fetch price from API...   await update.message.reply_text(f"{symbol}: $XX,XXX")app.add_handler(CommandHandler("price", price))```---
## Inline Keyboard — Interactive Menus```pythonfrom telegram import Update, InlineKeyboardButton, InlineKeyboardMarkupfrom telegram.ext import CallbackQueryHandlerasync def deals(update: Update, context):   keyboard = [       [InlineKeyboardButton("🔥 Today's Deals", callback_data="deals_today")],       [InlineKeyboardButton("📈 Trending Products", callback_data="deals_trending")],       [InlineKeyboardButton("❓ Help", callback_data="deals_help")],   ]   reply_markup = InlineKeyboardMarkup(keyboard)   await update.message.reply_text("Choose a category:", reply_markup=reply_markup)async def button_callback(update: Update, context):   query = update.callback_query   await query.answer()   data = query.data   if data == "deals_today":       await query.edit_message_text("🔥 Hot deals:\n1. Product A — $19\n2. Product B — $29")   elif data == "deals_trending":       await query.edit_message_text("📈 Trending now:\n1. Product X — $49\n2. Product Y — $39")   elif data == "deals_help":       await query.edit_message_text("Reply with /price <item> to check any product.")app.add_handler(CommandHandler("deals", deals))app.add_handler(CallbackQueryHandler(button_callback))```**Key point:** Call `query.answer()` immediately to acknowledge the callback; Telegram requires this within 30 seconds or the button shows a warning.---
## Conversation Handler — Multi-Step Forms```pythonfrom telegram.ext import ConversationHandler, MessageHandler, filtersAWAIT_PRODUCT, AWAIT_BUDGET = range(2)async def order_start(update: Update, context):   await update.message.reply_text("What product do you want to order?")   return AWAIT_PRODUCTasync def order_product(update: Update, context):   context.user_data["product"] = update.message.text   await update.message.reply_text("Great! What's your budget?")   return AWAIT_BUDGETasync def order_budget(update: Update, context):   context.user_data["budget"] = update.message.text   # Save to DB, route to fulfillment, etc.   await update.message.reply_text(       f"Order noted!\nProduct: {context.user_data['product']}\nBudget: {context.user_data['budget']}\nWe'll contact you."   )   return ConversationHandler.ENDasync def order_cancel(update: Update, context):   await update.message.reply_text("Order cancelled.")   return ConversationHandler.ENDconv_handler = ConversationHandler(   entry_points=[CommandHandler("order", order_start)],   states={       AWAIT_PRODUCT: [MessageHandler(filters.TEXT & ~filters.COMMAND, order_product)],       AWAIT_BUDGET:  [MessageHandler(filters.TEXT & ~filters.COMMAND, order_budget)],   },   fallbacks=[CommandHandler("cancel", order_cancel)],)app.add_handler(conv_handler)```---
## Error Handling — Graceful Recovery```pythonimport tracebackasync def error_handler(update: Update, context):   """Log errors and notify admin."""   tb = "".join(traceback.format_exception(None, context.error, context.error.__traceback__))   logging.error(f"Update {update.update_id} caused error:\n{tb}")   if update and update.effective_message:       await update.effective_message.reply_text("Sorry, something went wrong. Please try again later.")   # Optionally forward to admin chat   await context.bot.send_message(chat_id=ADMIN_CHAT_ID, text=f"Bot error:\n{chr(96)*3}\n{tb[:2000]}\n{chr(96)*3}")app.add_error_handler(error_handler)```---

## State Persistence```python# In-memory (default) — lost on restart# Pickle persistence — survives restart, single processapp = Application.builder().token(TOKEN).persistence(PicklePersistence("bot_state.pkl")).build()# Redis persistence — multi-process, multi-instance# pip install redis python-telegram-bot-persistence-redisfrom telegram.ext._utils.types import PersistenceInputfrom telegram.ext.persistence import RedisPersistencepersistence = RedisPersistence(   redis=redis.async_redis,   defaults=PersistenceInput(       bot_data=True,       chat_data=True,       user_data=True,       callback_data_cache=True,   ))app = Application.builder().token(TOKEN).persistence(persistence).build()```---

## Anti-Rationalization Table| Rationalization | Reality ||---
|---
|| "I'll just poll locally; webhooks are overkill" | Webhooks scale to thousands of users; polling breaks behind NAT, drains API quota, and introduces seconds of latency || "Inline keyboards are gimmicky, plain text is fine" | Keyboards drive 3-5x higher click-through on affiliate links; users tap instead of copy-paste || "Conversation handlers are too complex for my simple bot" | `ConversationHandler` is 15 extra lines and turns a dead-end bot into an order-taking machine || "I'll handle errors later" | One unguarded API call crashes the bot until next restart; `error_handler` is 10 lines of insurance || "python-telegram-bot handles everything out of the box" | No — every `run_polling` / `run_webhook` call blocks the main thread; separate process for scheduled broadcasts || "One bot is enough" | Multiple specialized bots per channel (affiliate, support, signals) outperform a single Swiss-army bot || "Telegram will moderate my bot away" | Follow ToS: no spam, opt-in only, user `/stop` respected instantly; compliant bots run for years |---
## Verification- [ ] Bot connects and responds to `/start` command- [ ] Command handler parses `context.args` correctly (`/price BTC` → symbol = "BTC")- [ ] Inline keyboard renders and callback triggers the right handler- [ ] `query.answer()` is called before `query.edit_message_text()` — no button timeout warning- [ ] Conversation handler walks through all states and terminates cleanly- [ ] Error handler catches malformed input, API failures, and rate limit errors without crashing- [ ] Webhook returns 200 for POST and accepts Telegram's test request- [ ] `setWebhook` response has `ok: true` and `getWebhookInfo` shows `pending_update_count: 0` after drain- [ ] Persistence survives process restart (data restored from pickle/Redis)- [ ] Rate limits: Telegram allows ~30 messages/sec; batch sends wait between chunks- [ ] `/stop` or `/leave` command deletes user data and stops interaction- [ ] Bot token is never hardcoded — loaded from environment variable---
