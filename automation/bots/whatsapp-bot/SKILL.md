# WhatsApp Bot — WAHA-Powered AutomationBuild and scale WhatsApp bots using **WAHA** (WhatsApp HTTP API) — a lightweight self-hosted REST/WebSocket service wrapping the WhatsApp Web protocol. No Meta Business approval, no template pre-approval, no BSP fees.---
## When to Use
- Setting up a WhatsApp broadcast bot for marketing or promotions without Meta Business approval- Building a WhatsApp-based customer support or lead qualification pipeline- Automating outbound messaging (transactional, appointment reminders, order updates)- Receiving and auto-replying to inbound WhatsApp messages via webhooks- Replacing Meta Cloud API when you need fast setup, no per-message cost, and full control- Running multiple WhatsApp numbers from a single container with named sessions- Prototyping WhatsApp automation before committing to Cloud API or BSP integration## Workflow
1. **Deploy WAHA** — Start the WAHA Docker container with the NOWEB engine, exposed REST port, and persistent session volume.2. **Create & scan session** — Call the `/api/sessions/{name}` endpoint to generate a QR code, then scan it from WhatsApp → Linked Devices on your phone.3. **Verify session** — Confirm the session transitions to `WORKING` status and WAHA health check returns 200.4. **Set up webhook** — Register a webhook endpoint with WAHA to receive incoming messages. Implement auto-reply logic for keywords or intents.5. **Send messages** — Use WAHA REST endpoints (`/api/sendText`, `/api/sendImage`, etc.) to send outbound messages, images, documents, and buttons.6. **Broadcast to subscribers** — Pull active phone numbers from your subscriber database and send messages with human-like delays (2-5s) to respect rate limits.7. **Monitor & maintain** — Track session health, handle reconnections, rotate sessions if blocked or expired. Scale to multiple sessions or migrate to Cloud API as volume grows.## Quick Start — WAHA with DockerWAHA exposes the full WhatsApp Web stack through clean REST endpoints. ## Send a Text Message```pythondef send_text(session: str, chat_id: str, text: str) -> dict:   """Send a plain text message."""   resp = requests.post(       f"{WAHA_URL}/api/sendText",       json={"session": session, "chatId": chat_id, "text": text},   )   resp.raise_for_status()   return resp.json()send_text("default", "628123456789@c.us", "🔥 *Deal Alert!* 50% off today!")```**chatId format:** `<country_code><number>@c.us` (individual), `<group_id>@g.us` (groups).Markdown (`*bold*`, `_italic_`, `` `code` ``) renders in WhatsApp.---
## Send an Image```pythondef send_image(session: str, chat_id: str, image_url: str, caption: str = "") -> dict:   """Send an image from a public URL."""   resp = requests.post(       f"{WAHA_URL}/api/sendImage",       json={"session": session, "chatId": chat_id, "file": image_url, "caption": caption},   )   resp.raise_for_status()   return resp.json()send_image("default", "628123456789@c.us",          "https://example.com/promo.jpg",          "Limited time offer!")```Local file upload via multipart form-data:```bashcurl -X POST http://localhost:3000/api/sendImage \ -F "session=default" \ -F "chatId=628123456789@c.us" \ -F "file=@promo.jpg" \ -F "caption=Check this out!"```---

## Broadcast Workflow```┌──────────────┐     ┌──────────────┐     ┌──────────────┐│  WAHA        │     │  Bot Logic   │     │  Subscriber  ││  Container   │◄────│  (Python)    │────►│  DB (SQLite) │└──────────────┘     └──────────────┘     └──────────────┘      │                     │      │  Inbound msg        │  Outbound (broadcast / reply)      ▼                     ▼┌──────────────┐     ┌──────────────┐│  User Phone  │     │  Webhook     ││  (WhatsApp)  │────►│  Endpoint    │└──────────────┘     └──────────────┘```### Full Broadcast Script```python"""broadcast.py — Staggered bulk messaging."""import requests, sqlite3, osfrom time import sleepWAHA_URL = os.environ.get("WAHA_URL", "http://localhost:3000")SESSION = "default"def get_active_subscribers() -> list[str]:   conn = sqlite3.connect("subscribers.db")   conn.execute("CREATE TABLE IF NOT EXISTS subscribers (phone TEXT PRIMARY KEY, active INTEGER DEFAULT 1)")   rows = conn.execute("SELECT phone FROM subscribers WHERE active=1").fetchall()   conn.close()   return [r[0] for r in rows]def broadcast(promotion: str, delay: float = 3.0):   subs = get_active_subscribers()   sent = failed = 0   for phone in subs:       try:           r = requests.post(f"{WAHA_URL}/api/sendText", json={               "session": SESSION, "chatId": f"{phone}@c.us", "text": promotion,           })           if r.status_code == 201:               sent += 1           else:               failed += 1       except requests.RequestException:           failed += 1       sleep(delay)   print(f"Sent {sent}, failed {failed}")if __name__ == "__main__":   broadcast("🔥 Exclusive: 50% off for subscribers!", delay=2.0)```**Rate limits:** WhatsApp Web allows ~20-50 msg/min per device. Always `sleep(2)` between sends. For >500 recipients, stagger over hours.---
