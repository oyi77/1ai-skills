# n8n Buildern8n is the leading open-source workflow automation platform (self-hosted). 400+ nodes, visual drag-and-drop editor, custom JS/Python code nodes, and full REST API control.See parent skill for Docker deployment, hosted service model, and money-making workflows.
## When to Use
Use n8n when you need to automate multi-step workflows that span 3+ services (CRMs, email, databases, AI models, cloud storage) and benefit from visual debugging, retry logic, and audit trails that are harder to maintain with custom-coded scripts alone. Well-suited for client-facing automation products, data pipelines between SaaS tools, and scheduled reporting — especially when the integration doesn't already exist in Make.com or Zapier's free tiers. Prefer a dedicated programming language for complex branching logic (20+ conditional paths) or sub-millisecond latency requirements; n8n shines at the 80% of automations that chain REST APIs, condition branches, and error handlers together in a visually inspectable graph.---

## Workflow
 Design PatternEvery production n8n workflow follows this architecture:```[TRIGGER] → [VALIDATE] → [TRANSFORM] → [ACTION] → [HANDLE ERROR]```### 1. TriggerReceive an event: webhook, cron, poll, or manual.### 2. ValidateCheck inputs before processing. Use IF + Code nodes:```javascript// Code node — input validationconst { email, amount } = $input.item.json;if (!email || !email.includes('@')) {   throw new Error(`Invalid email: ${email}`);}if (typeof amount !== 'number' || amount <= 0) {   throw new Error(`Invalid amount: ${amount}`);}return $input.item;```### 3. TransformMap, enrich, or reshape data:```python# Code node — Python: reshape API responsedef transform(item):   raw = item.json   return {       'id': raw['data']['id'],       'name': raw['data']['attributes']['name'],       'email': raw['data']['attributes']['email'],       'created': raw['data']['attributes']['created_at'][:10],       'tags': [t['name'] for t in raw['data']['attributes'].get('tags', [])]   }return [transform(item) for item in items]```### 4. ActionExecute side effects — send email, update CRM, post to Slack, call API.### 5. Handle ErrorWire the **Error** output (red connector) to:- Retry logic with exponential backoff- Slack/Telegram alert on failure- Dead-letter queue (write to file or database)```javascript// Error handler sub-workflow pattern// In the error output of an HTTP Request node:// 1. Wait node (60 seconds)// 2. HTTP Request node (retry)// 3. IF node: if still failing → Slack alert + Stop```---
## Custom Code Node Examples### JavaScript — Webhook Payload Transformation```javascript// Transform incoming webhook to n8n item formatconst webhookData = $input.item.json;// Normalize field names from snake_case to camelCaseconst normalized = {   orderId: webhookData.order_id || webhookData.OrderId,   customerEmail: webhookData.customer_email || webhookData.Email,   totalAmount: parseFloat(webhookData.total_amount || webhookData.Total || 0),   currency: (webhookData.currency || 'USD').toUpperCase(),   items: (webhookData.items || []).map(item => ({       sku: item.sku,       qty: parseInt(item.quantity || item.qty || 1),       price: parseFloat(item.price || item.unit_price || 0)   }))};// Validate required fieldsif (!normalized.orderId) {   throw new Error('Missing required field: orderId');}return { json: normalized };```### Python — Enrich with External API```python# Fetch enrichment data from an external APIimport requestsdef enrich(item):   raw = item.json   email = raw.get('email', '')   if not email:       return item   # Call enrichment service   try:       resp = requests.get(           f"https://api.enrichment.example/v1/person",           params={'email': email},           headers={'Authorization': f'Bearer {os.getenv("ENRICH_API_KEY")}'},           timeout=5       )       resp.raise_for_status()       data = resp.json()       raw['enriched'] = {           'name': data.get('fullName'),           'company': data.get('company'),           'role': data.get('jobTitle'),           'linkedin': data.get('linkedinUrl')       }   except requests.RequestException as e:       # Soft fail: log but don't block the workflow       raw['enriched'] = {'error': str(e)}   return rawresults = [enrich(item) for item in items]```### JavaScript — Batch Processing with Rate Limiting```javascript// Process items in batches with configurable concurrencyconst batchSize = 5;const delayMs = 1000;const allItems = $input.all();const results = [];for (let i = 0; i < allItems.length; i += batchSize) {   const batch = allItems.slice(i, i + batchSize);   // Process batch concurrently   const batchResults = await Promise.allSettled(       batch.map(async (item) => {           const response = await fetch(item.json.apiUrl, {               method: 'POST',               headers: { 'Content-Type': 'application/json' },               body: JSON.stringify(item.json.payload)           });           return { original: item.json, response: await response.json() };       })   );   results.push(...batchResults.map(r =>       r.status === 'fulfilled' ? r.value : { error: r.reason.message }   ));   // Rate limit between batches   if (i + batchSize < allItems.length) {       await new Promise(r => setTimeout(r, delayMs));   }}return results;```---

## Credential Managementn8n stores credentials encrypted at rest using `N8N_ENCRYPTION_KEY`. Best practices:| Practice | Why ||---
|---
|| Use unique credentials per environment | Prevent dev credentials touching production || Set `N8N_ENCRYPTION_KEY` as environment variable | Required for docker restart credential preservation || Use n8n's credential variables (`$credentials`) | Avoid hardcoding secrets in code nodes || Rotate keys quarterly | Limit blast radius of a leak || Never share credential exports | Exported workflow JSON contains encrypted credentials |Access credentials in code nodes:```javascript// Access stored credential in Code nodeconst slackCreds = $credentials.slackApi;console.log(slackCreds.accessToken);   // n8n handles decryption```---
