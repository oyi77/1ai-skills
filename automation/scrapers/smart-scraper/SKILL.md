# Smart ScraperProduction-grade web scraping toolkit: static HTML parsing, JavaScript-rendered content extraction, anti-blocking techniques, and scheduled collection pipelines.
## When to Use
Use when you need to extract structured data from any website — product catalogs, listings, pricing, reviews, or other repetitive content — at a cadence of one-off fetches through continuous monitoring. This skill covers the full pipeline: inspect, selectors, fetch, parse, store, schedule.## Quick Start```pythonimport httpxfrom bs4 import BeautifulSoupdef fetch_page(url: str) -> BeautifulSoup:   response = httpx.get(url, headers={"User-Agent": "Mozilla/5.0"}, timeout=15, follow_redirects=True)   response.raise_for_status()   return BeautifulSoup(response.text, "html.parser")soup = fetch_page("https://example.com/products")print(soup.title.text.strip())```Install dependencies:```bashpip install httpx beautifulsoup4 lxml````lxml` is recommended over the built-in `html.parser` — it is 3-5x faster and more tolerant of broken markup. Layer these defenses in order of impact:### 1. Rotate User-Agent```pythonimport randomUSER_AGENTS = [   "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/125.0.0.0 Safari/537.36",   "Mozilla/5.0 (Macintosh; Intel Mac OS X 14_5) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.5 Safari/605.1.15",   "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/125.0.0.0 Safari/537.36",]def random_headers() -> dict:   return {       "User-Agent": random.choice(USER_AGENTS),       "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",       "Accept-Language": "en-US,en;q=0.5",   }```### 2. Rate Limiting & Retries```pythonimport timeimport httpxclient = httpx.Client(headers=random_headers(), timeout=15)def polite_get(url: str, delay: float = 2.0, retries: int = 3) -> httpx.Response:   for attempt in range(retries):       try:           time.sleep(delay * (1 + random.random()))  # jitter           resp = client.get(url)           resp.raise_for_status()           return resp       except httpx.HTTPStatusError as e:           if e.response.status_code == 429:  # too many requests               wait = int(e.response.headers.get("Retry-After", 10))               time.sleep(wait)               continue           raise       except (httpx.ConnectError, httpx.ReadTimeout):           if attempt == retries - 1:               raise           time.sleep(5 * (attempt + 1))   raise RuntimeError("exhausted retries")```### 3. Proxy Rotation```pythonPROXIES = [   "http://user:pass@proxy1.example:8080",   "http://user:pass@proxy2.example:8080",]def rotating_client():   proxy = random.choice(PROXIES)   return httpx.Client(proxies=proxy, headers=random_headers(), timeout=15)```### 4. |---
|| "I can just use `requests` without a session" | Without retry + rate-limit logic, a single 429 or timeout loses all data. Always use a client with backoff. || "Selectors will work forever" | Sites change markup. Pin selectors but expect breakage — log parse failures separately from HTTP failures. || "Headless browser is always better" | Playwright is 10-50x heavier than httpx. Use it only for JS-rendered content, never for plain HTML. || "A single User-Agent is fine" | Many CDNs block non-browser UAs outright. Rotate from a pool of real browser strings. || "I'll just scrape without delays" | Most sites will rate-limit or ban your IP within 20-50 requests. Polite scraping with jitter outlasts aggressive scraping. || "Playwright stealth init scripts are optional" | Cloudflare Turnstile and DataDome detect headless Chrome via `navigator.webdriver`. The init script override is mandatory for those targets. |## Verification1. **Run a single-product scrape** against a stable target — confirm title, price, and image fields are non-empty and match the page.2. **Test pagination** — scrape a listing with 3+ pages and verify the result count matches manual page-count × items-per-page.3. **Test JS rendering** — open the Playwright target URL, confirm `page.content()` contains elements that are absent from `httpx.get().text`.4. **Test anti-blocking** — run the polite scraper without proxies and confirm it handles 429 gracefully (log shows retries, not crashes).5. **Test storage** — run the full pipeline end-to-end and verify the output file/table has the expected structure and row count.6. **Edge cases** — blank page, missing selector, redirect loop, gzip-compressed response, site behind login wall (confirm early abort).7. **Respect robots.txt** — check that `Disallow` paths are skipped before fetching.
