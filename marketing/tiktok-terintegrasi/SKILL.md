# The 9 Workflows

Tiktok Terintegrasi operates 9 specialized content generation pipelines. Every workflow outputs platform-native 9:16 video or image ready for upload.

## Workflow 1: Product Image → AI Video

**Input:** 1 product image + text prompt  
**Output:** 9:16 video with AI-generated motion (NVIDIA NIM or Kling AI)  
**Process:**
1. Upload product image to NVIDIA NIM image-to-video API
2. Set prompt describing product movement (rotate, zoom, sparkle)
3. Download 4-5s generated video
4. Overlay brand caption + CTA text with ffmpeg

## Workflow 2: Text-to-Video (Seedance)

**Input:** Text script (30-60 words)  
**Output:** AI-generated 9:16 video matching the script  
**Process:**
1. Compose hook-driven script (3 sentences max)
2. Submit to BytePlus Seedance API
3. Crop to 9:16 if needed
4. Add background music + text overlay

## Workflow 3: Video-to-Video Style Transfer (Kling AI)

**Input:** Raw footage or screen recording  
**Output:** Stylized video (3D, anime, cinematic)  
**Process:**
1. Upload raw clip to Kling AI
2. Select style preset
3. Download transformed 9:16 video
4. Add watermark or logo overlay

## Workflow 4: AI Voiceover (ElevenLabs)

**Input:** Script text  
**Output:** Professional voiceover audio file  
**Process:**
1. Paste script (50-100 words TikTok-optimized)
2. Select voice (casual US, energetic, or brand-cloned)
3. Generate MP3
4. Sync with video using ffmpeg

## Workflow 5: Caption + Subtitle Burn-In

**Input:** Video + script  
**Output:** Video with burned-in TikTok-style captions  
**Process:**
1. Transcribe audio to SRT (whisper-ctranslate3 or API)
2. Style captions: yellow/white text, black outline, center-bottom
3. Burn subtitles into video with ffmpeg `subtitles` filter
4. Add animated lower-third for CTAs

## Workflow 6: Hook & Hashtag Generation

**Input:** Product name + target audience  
**Output:** 5 hook variations + 20 hashtags  
**Process:**
1. Generate 5 hook templates using LLM:
   - "Stop scrolling if you [pain point]"
   - "I tried [product] for 7 days..."
   - "This [$X] thing from TikTok actually works"
2. Generate 20 hashtags (3 broad, 10 niche, 7 branded)
3. Select top performer by client's historical data

## Workflow 7: Multi-Platform Repurposing

**Input:** One 9:16 TikTok video  
**Output:** 3 platform-specific versions  
**Process:**
1. **TikTok:** Keep 9:16, add trending sound, hook in first 2s
2. **Instagram Reels:** 9:16, add Reels-specific caption (CTA to link in bio)
3. **YouTube Shorts:** 9:16, add #shorts tag, title-optimized description

## Workflow 8: Bulk Content Calendar Generation

**Input:** Product catalog (3-20 products)  
**Output:** 30-day content calendar with scheduled posts  
**Process:**
1. For each product, run Workflows 1-4 to generate base video
2. Generate 3 hook variations per product (Workflow 6)
3. Schedule across 30 days: 1 post/day at peak TikTok hours (7PM-9PM local)
4. Batch upload to PostBridge API for scheduled posting

## Workflow 9: Performance Analytics & Iteration

**Input:** PostBridge post results (views, shares, CTR)  
**Output:** Optimization recommendations for next batch  
**Process:**
1. Pull post results from PostBridge API
2. Rank videos by engagement rate
3. Identify top-performing hook pattern
4. Double down on winning formula for next batch
5. Flag underperformers for hook/caption rewrite

## Key Metrics

- **Views per video:** Target 1,000+ organic in first 48h
- **Engagement rate:** >5% (likes + comments + shares / views)
- **Click-through rate:** >1.5% (link clicks / impressions)
- **Production speed:** <15 min per finished video (all workflows)
- **Cost per video:** $0.50-2.00 in API costs (AI inference + TTS)
- **Client retention:** >80% month-over-month for recurring plans

## Best Practices

- **Hook in first 2 seconds:** If you don't grab attention by second 2, they scroll. Use pattern interrupts (text pop, zoom, color flash).
- **One product, one video:** Never feature multiple products in one TikTok. Each video sells one thing.
- **Sound is 50% of the video:** Use trending sounds for organic reach. Voiceover alone underperforms.
- **Post daily at 7PM local:** Consistency beats perfection. Batch-generate 30 videos, schedule 30 days.
- **A/B test hooks:** Same product video with 3 different hooks → winner gets boosted.
- **Caption = CTA:** Every caption must end with an action (link in bio, comment YES, DM for price).
- **9:16 only:** Landscape videos on TikTok are dead on arrival. Always crop/pad to 9:16.

# First Action in 60 Minutes

Generate your first client-ready TikTok video from a product image. Copy-paste this:

```bash
#!/usr/bin/env bash
set -euo pipefail

# === CONFIG ===
PRODUCT_IMAGE="${1:-product.jpg}"        # Path to product image
SCRIPT="${2:-"This \$29 gadget changed my mornings forever. Link in bio."}"
VOICE="${3:-"21m00Tcm4TlvDq8ikWAM"}"     # ElevenLabs Rachel voice
OUTPUT="${4:-tiktok_video.mp4}"

# === STEP 1: Generate AI video from product image ===
# Uses NVIDIA NIM image-to-video (free tier available via nim.replicate.ai)
# Fallback: use ffmpeg ken burns effect if no API key

echo "[1/4] Generating AI video from product image..."
if [ -n "${NIM_API_KEY:-}" ]; then
  curl -s -X POST "https://nim.replicate.ai/v1/image-to-video" \
    -H "Authorization: Bearer $NIM_API_KEY" \
    -H "Content-Type: application/json" \
    -d "{\"image\":\"data:image/jpeg;base64,$(base64 -w0 "$PRODUCT_IMAGE")\",\"prompt\":\"product rotating slowly, cinematic lighting, smooth motion, 4k quality\"}" \
    --output /tmp/raw_video.mp4
else
  # No API key: ken burns zoom + product overlay
  ffmpeg -y -loop 1 -i "$PRODUCT_IMAGE" -c:v libx264 -t 5 -pix_fmt yuv420p \
    -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,zoompan=z='min(zoom+0.001,1.1)':d=125:fps=24" \
    /tmp/raw_video.mp4 2>/dev/null
fi

# === STEP 2: Generate voiceover ===
echo "[2/4] Generating AI voiceover..."
if [ -n "${ELEVENLABS_API_KEY:-}" ]; then
  curl -s -X POST "https://api.elevenlabs.io/v1/text-to-speech/$VOICE" \
    -H "xi-api-key: $ELEVENLABS_API_KEY" \
    -H "Content-Type: application/json" \
    -d "{\"text\":\"$SCRIPT\",\"model_id\":\"eleven_multilingual_v2\",\"voice_settings\":{\"stability\":0.5,\"similarity_boost\":0.75}}" \
    --output /tmp/voiceover.mp3
else
  echo "No ELEVENLABS_API_KEY set. Using silent video. Set up free account at elevenlabs.io"
  ffmpeg -y -f lavfi -i anullsrc=r=44100:cl=mono -t 5 /tmp/voiceover.mp3
fi

# === STEP 3: Combine video + audio + captions ===
echo "[3/4] Compositing final TikTok video..."
DURATION=$(ffprobe -v error -show_entries format=duration -of csv=p=0 /tmp/raw_video.mp4)

# Burn caption overlay (white text, black outline, bottom third)
ffmpeg -y -i /tmp/raw_video.mp4 -i /tmp/voiceover.mp3 \
  -filter_complex "\
    [0:v]drawtext=text='$(echo "$SCRIPT" | head -c 60)...':fontsize=32:fontcolor=white:bordercolor=black:borderw=2:x=(w-text_w)/2:y=h-th-120:enable='between(t,0,3)'[v]" \
  -map "[v]" -map 1:a -c:v libx264 -c:a aac -shortest -pix_fmt yuv420p \
  "$OUTPUT"

echo "[4/4] Done! Output: $OUTPUT"
echo "Duration: ${DURATION}s"
echo "Upload to TikTok via PostBridge or manual upload."
```

**Run it:**
```bash
bash generate_tiktok.sh product.jpg "This \$29 gadget changed my mornings forever."
```

**What you bill the client:** $50/video. Three clients at 10 videos/month = $1,500/mo recurring. This script is your production floor.
